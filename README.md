## Problema que resuelve

El chatbot tiene la funcion de resolver dudas escolares a los alumnos sobre todo en la epoca de inscripcion. 

## Objetivo del sistema

Ayudar y guiar a los alumnos de una institucion para que puedan hacer sus inscripciones sin ningun problema asi como conocer las materias y profesores.

## Funcionalidades

- Responder preguntas frecuentes universitarias.
- Procesar texto mediante TF-IDF y similitud coseno.
- Clasificar consultas por categoría.
- Mostrar un dashboard con estadísticas.
- Identificar preguntas que no puede responder.
